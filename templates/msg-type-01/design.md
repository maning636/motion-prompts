# 聊天输入条打字 视觉规范

## 方向

画面左侧是方形手机壳：对方一句「这期讲什么」，然后**输入条自己活过来**——内容逐字写出（每字 0.05s），光标是一块 4px 黑方块每 0.24s 硬闪一次；发送键压一下，输入框清空回占位字，一条绿气泡落下来。右侧观点区是 112px 单行大字「打一半就发出去」、副标题、规则线、三个胶囊标签。

这条是 msg 族里唯一给**输入条**做动画的一件，而且等待的是「自己」：观众盯着的是编辑到一半的犹豫，不是对方那边的悬念。

## Palette

- Background: `#FFF6E5`（纸底）
- Foreground: `#0F0F0F`（描边 / 文字唯一来源）
- Accent: `#FF5FA2`（发送按钮底 / 第一个要点标签 / 斜纹带 / 头像方块；默认值是变量，换行业只改一个值）
- Muted: `#6B6B6B`（占位字 / 次级说明）
- Chat grey: `#EDEDED`（聊天窗底色，变量 `--wa-grey`）
- Chat green: `#95EC69`（自己发出去的气泡，变量 `--wa-green`）
- Chat red: `#FA5151`（未读角标 / 红点，变量 `--wa-red`）
- Border: `#0F0F0F`（3px 硬描边，全文件唯一线宽）
- Stripe: `repeating-linear-gradient(45deg, #0F0F0F 0 10px, #FF5FA2 10px 20px)`

> 三个聊天 UI 色全部收进 CSS 变量，不写死。它们是行业通行的聊天 UI 色，不是受商标保护的
> 标识；本模板不复制任何官方素材（无应用 logo、无真人头像、无官方界面截图），
> 全部形状纯 CSS 重绘。换成 QQ 蓝或微博橙只改 `--wa-green` 一个 token。

## Typography

- 主标题：`Noto Sans SC`，字重 900，112px（中文大字恒 0 字距）
- 副标题 / 气泡正文：`Noto Sans SC`，字重 700，32px / 23px，字距 0
- 眉标 / 时间条 / 标签：`Sarasa Gothic SC`，字重 700，16–26px，字距 .06–.14em
- 金额与计数字：`Sarasa Gothic SC` + `font-variant-numeric:tabular-nums`（跳数时不抖位宽）

## 布局

- 画布 1920×1080，`#stage` 锁定尺寸并 `overflow:hidden`
- 纵向四段：通告条 56px → 主区（自适应，938px）→ 斜纹带 20px → 页脚 66px
- 主区**手机壳在左、观点区在右**：手机壳 466×840 固定宽，与观点区之间 52px 间距
- 手机壳 466×840（高度是算出来的：1080 − 56 − 20 − 66 − 上下内边距 74 = 864，留 24 余量）
- 手机壳内四段：状态条 40px → 聊天头 66px（3px 下边线分隔）→ 消息流（flex-end，气泡从底部往上长）→ 输入条 76px（3px 上边线分隔）
- 头像 46×46 方块 + 单字占位；气泡 `max-width:300px`，内边距 11px 14px
- 右侧观点区：眉标 → 112px 单行主标题 → 32px 副标题 → 3px 规则线 → 三个 9999px 胶囊标签
- 安全边距贴边元素从 72px 起步，不贴 0

## 动画

- 壳体五件错峰落位；提问 0.78s 硬着陆
- **打字机 1.30s 起，每字 0.05s**（`tl.call` 逐字写 textContent，不做逐帧滚动）；打完后光标块每 0.24s 硬闪一次、共 4 轮（`steps(1)`，不用 opacity 渐变）
- **发送 2.26s**：按钮阴影 0 → 3px 压下 → 恢复（steps(2)），输入框清空回占位字，光标隐藏；2.40s 绿气泡从右下 26px、30px 硬着陆
- 右侧观点区并行：主标题 1.16s → 副标题 1.48s → 规则线 1.72s → 标签 1.86 / 2.00 / 2.14s

- **所有运动在 4.18s 前收干净**（76% × 5.5s 是 motion-qc 落定期起点），
  尾部静止 hold 到总时长——落定期扫到还没落定的元素会直接判出框
- 演完定格最后一帧，无收尾 fade-out
- 降级分支：两条消息一次性全在，输入框直接是 typed 的完整文本（成品画面 = 打完之后的状态），时间轴 2.3s

## Avoid

- 不复制任何聊天应用的商标素材：无双气泡 logo、无官方头像、无应用名字样
- 气泡尾巴用 border 三角 / clip-path 切角，**不用 `border-radius:50%`**——圆角只有 4px 与 9999px 两档
- 圆角只允许 `4px` 与 `9999px`；描边恒 3px；阴影恒 `Npx Npx 0` 且 X=Y，永不写第四个值
- 零 overshoot：不出现 `back.*` / `elastic.*` / `bounce.*` / `sine.*`，入场一律 `power4.out`
- 不用 opacity 淡入当主入场手段；不用 `repeat:-1` 做无限循环（改为显式排若干轮）
- 不用 `rotate` / `skew`，所有元素 rotation 恒为 0
- 一次只出一条消息，不在第 0 帧把整串对话倒出来
- **降级媒体查询必须同时写 `transition-property:none`**——只压 duration 会让 JS 写的内联几何
  变成 0.01ms 的过渡，元素卡在 CSS 旧值上（aud 族实测，agent-114 复现）
- 气泡文案变量 **上限 14 字**：气泡是 flex 项，`B.fit()` 抓不到它的收缩，超 14 字必须换文案，不许靠缩字号
- 派生量必须派生：状态条数字、剩余条数、大数字面板都从 `amount` / `unread` / `waitSec` 算，不另开变量
- **`typed` 与 `sent` 必须是两个变量**：它们的差就是「打一半就发」，用一个变量会把这个笑点抹平
- 光标是 4px 圆角**方块**，闪动用 `steps(1)` 硬切，不用淡入淡出
- 打字机不改时间轴总长：`typed` 上限 18 字（18 × 0.05 = 0.9s），超了换文案

## 配套

- 音轨：无（本模板不吃音频）
- 样片格式：mp4。本件是实底件，不需要 alpha 捕获；用 webm 会走 alpha 通道把 stage 底色剥掉
- 渲染样片：走 hyperframes 0.8.55 的 render 流程，时长取 `duration` 变量（5.5s）
- 同族参考：`msg-drip-01`（逐条滴落的节奏基准）、`msg-transfer-01`（转账卡的卡面语法）
- 本批**不建 `presets/`**：配色方案直接改 `accent` 变量即可，第二个配色需求出现时再补目录
  （渲染命令里的 preset 入参由渲染批次统一处理，本批不预置）
