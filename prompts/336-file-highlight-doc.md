# 文件高亮扫描件（档案拼贴）

> 分类：字幕与重点标注 ｜ 时长：6s ｜ 在线预览：https://motion.maning789link.top

把下面整段提示词粘贴给任意 AI（Claude Code / Codex / 豆包 / DeepSeek……）即可生成同款动效。

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】文件高亮扫描件（档案拼贴）
【分类】字幕与重点标注
【用途】整页扫描文件：文字行逐行落定后，黄色马克笔按行号逐段扫过高亮关键段。适合讲条款解读、重点划线、文档拆解。
【标签】档案拼贴 / 扫描件 / 高亮 / 文件
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
档案 token。SCAN COPY 扫描件头 + 整页文字行，高亮行为行内 absolute 黄条 scaleX 扫过（opacity .8 马克笔感），行号变量可控扫哪几行。
【可改文案】文件标题（默认「平台分成规则（节选）」）、正文行（逗号分隔）（默认「第一条 基础分成比例为流水的一半,第」）、高亮行号（逗号分隔，从1计）（默认「2,4」）、总时长(秒)（默认「6」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
