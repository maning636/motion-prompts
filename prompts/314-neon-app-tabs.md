你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】霓虹应用双Tab
【分类】信息卡片
【用途】深黑底荧光绿双Tab切换：标题关键词绿色高亮，两个并排圆角按钮（彩点+主副标签）初始激活Tab1，2.2s激活态切到Tab2并横扫闪光，说明字同步淡入，适合口播讲同一产品的不同入口/叫法。
【标签】Tab切换 / 霓虹 / 荧光绿 / 入口对比
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格最后一帧。
【可改文案】顶部英文小标签（默认「WHERE TO FIND」）、中文标题（含高亮词）（默认「同一个东西，各家叫法不同」）、标题高亮词（绿色，须为标题子串）（默认「各家」）、灰色副标题（默认「一个入口，两种打开方式」）、Tab1 主标签（默认「手机版」）、Tab1 副标签（灰小字）（默认「App 内打开」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
