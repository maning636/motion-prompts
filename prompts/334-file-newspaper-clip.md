你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】报纸剪报（档案拼贴）
【分类】信息卡片
【用途】竖排报栏剪报：撕纸边白报 + 报头 + 竖排正文分栏，黄色马克笔高亮关键句扫入。适合讲媒体报道、舆论、引用佐证。
【标签】档案拼贴 / 剪报 / 竖排 / 高亮
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
档案 token。writing-mode vertical-rl + column-width 竖排分栏报栏，clip-path 九点多边形撕纸边，报头双线分隔。高亮句包 span 黄底 #F5D73F clip 扫入。竖排是与全族其他横排成员的最大区分点。
【可改文案】报头（默认「科技观察报」）、正文段（默认「本报获悉，多家内容团队已开始把脚本、」）、高亮句（须为正文子串）（默认「生产周期从三天压缩到四小时」）、总时长(秒)（默认「6」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
