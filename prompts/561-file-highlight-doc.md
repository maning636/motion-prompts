你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】文件高亮扫描件（档案拼贴）
【分类】公文档案·文字与收尾
【用途】企业宣传场景的文字与收尾：文件高亮扫描件（档案拼贴）。
【标签】file-highlight-doc
【画幅】1920×1080
【时长】5 秒，动画确定性、首尾可循环

【视觉与设计规范】
- ID: file-highlight-doc
- 风格：公文表单风：米色纸底 + 公文纸白 + 墨绿表头线与标题下划 + 公文红 accent（红章/红圈/红批注）；逐行盖章式入场（power4.in 砸章），红圈用 SVG 描边绘制，演完定格。
- 动效：档案 token。SCAN COPY 扫描件头 + 整页文字行，高亮行为行内 absolute 黄条 scaleX 扫过（opacity .8 马克笔感），行号变量可控扫哪几行。

【可改文案】文件标题（默认「平台分成规则（节选）」）、正文行（默认「第一条 基础分成比例为流水的一半,第二条 独家内容额外奖励一成,第三条 每月结算一次逾期顺延,第四条 违规内容取消当月全部奖励,第五条 规则解释权归平台所有」）、高亮行号（默认「2,4」）、总时长（默认「5」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
