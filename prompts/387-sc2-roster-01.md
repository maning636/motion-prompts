你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】列表逐行显影
【分类】信息卡片
【用途】纸面列表行先显骨架灰条，逐行显影成真实文字，关键行绿高亮。
【标签】列表 / 显影 / 骨架 / 差异化复刻
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
纸白 #F6F5EF + 36px 细网格底；顶部细线页眉（左 SC2 栏目 + 右 P.392/400 页码 mono），居中 52px 眉题大标题 + mono 参数行。中央 1180px 纸面列表面板（白底 + 3px 墨黑边 + 14px 硬偏移投影）携 5 行骨架灰条（圆点 + 双灰条 + 页码条）expo.out 入场；随后逐行显影，每行 0.55s 一拍：骨架层 scaleX 收向右侧淡出，真实内容（墨黑圆形编号头像 + 标题 MEBHeiHeiTi 900 + 说明 MiSans + 行尾 mono 页码 P.0x/05）从 blur(8px) 显影到清晰。hlRow 行在文字显影后整行垫荧光绿色块 scaleX 扫入，说明与页码转墨黑。全程面板另有 12→-10px 线性慢漂移（与逐行显影解耦的第二层运动），时间轴盖满 6s 定格，无收尾 fade-out。底部荧光绿署名条（@老马AI研习社）。
【可改文案】页眉左（卷/栏目）（默认「SC2 · 差异化复刻」）、页眉右（页码）（默认「P.392 / 400」）、眉题（默认「LIST REVEAL · 逐行显影」）、列表行（标题|说明，分号分隔）（默认「选题库|每周更新的灵感仓库;素材夹|」）、高亮第几行（1 起）（默认「3」）、强调色（默认「#00FF00」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
