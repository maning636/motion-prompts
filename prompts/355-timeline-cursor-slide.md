# 固定光标时间尺（模式特效）

> 分类：数据可视化 ｜ 时长：6s ｜ 在线预览：https://motion.maning789link.top

把下面整段提示词粘贴给任意 AI（Claude Code / Codex / 豆包 / DeepSeek……）即可生成同款动效。

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】固定光标时间尺（模式特效）
【分类】数据可视化
【用途】固定光标+连续时间尺滑动：不是指针跑是刻度跑，每年小刻度、5 年大刻度+年份文字，光标带底部光晕从底部生长入场，刻度尺平移由主 progress 驱动，超大年份计数器同步跳动。
【标签】时间轴 / 刻度尺 / 固定光标 / 年份
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
深色底 #060806 + 荧光绿 #00FF00。刻度尺 div 由 JS 按起止年份生成（每年小刻度 22px、5 年大刻度 46px+mono 年份），translateX = 光标X - (当前年-起始年)*64px，挂主 progress 2.5s power1.inOut；光标为白色渐变竖线 origin bottom scaleY 生长 0.9s + 底部 radial 光晕 screen 混合。演完定格末帧。
【可改文案】起始年份（默认「1975」）、结束年份（默认「2055」）、标题（默认「五十年技术演进」）、强调色（默认「#00FF00」）、总时长(秒)（默认「6」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
