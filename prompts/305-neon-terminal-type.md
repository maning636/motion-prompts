# 荧光终端打字卡

> 分类：产品演示 ｜ 时长：6s ｜ 在线预览：https://motion.maning789link.top

把下面整段提示词粘贴给任意 AI（Claude Code / Codex / 豆包 / DeepSeek……）即可生成同款动效。

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】荧光终端打字卡
【分类】产品演示
【用途】深黑底荧光绿终端窗口：命令逐字打出后绿色高光横扫执行，输出行级联、状态行弹入定格，适合演示一句话指令触发自动执行。
【标签】终端 / 打字机 / 霓虹 / 荧光绿
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
荧光绿口播包装族的"自有签名"模板：macOS 风终端窗口内逐字打字 → 绿色高光横扫（回车执行）→ 输出行 cascade → 状态行弹入，光标闪 3 次后定格。
【可改文案】英文小标签（全大写）（默认「ONE LINE COMMAND」）、中文标题（默认「说一句，它就照做」）、标题高亮词（绿色，须为标题子串）（默认「说一句」）、命令文本（逐字打出）（默认「初始化 个人工作台生成器」）、输出行 1（默认「读取你的偏好设置」）、输出行 2（默认「生成 5 个功能模块」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
