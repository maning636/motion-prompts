你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】花瓣蒙版旋转换场（模式特效）
【分类】转场
【用途】八瓣花 SVG 蒙版在右半部局部圆形窗口内旋转 360°/2s（转蒙版不转照片），新图晚半拍 0.28s 向上推入窗口同终点，全屏压暗底图微放大 0.05 防接缝，左侧标题文案区，描边露照片像素自动取色，到位定格。图集轮换转场用。
【标签】转场 / 花瓣蒙版 / SVG mask / 旋转
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
构图三段：全屏压暗底图（brightness .55 + bgZoom 1.05 视差不硬推）+ 左侧标题区（大标题/英文小标/逗号两行文案/分割线/署名）+ 右半部局部花瓣窗口（圆形区圆心 68% 宽、52% 高，直径 62% 画面高，细白圈描边，窗口外保持压暗底图）。r=R·(0.60+0.40·cos(p·θ)) 八瓣路径，mask userSpaceOnUse 钉在窗口、内部 g 旋转 360°/2s 匀速——窗口在扫、窗里景物不动；内外两圈同角同速（内圈 smallScale 0.62 实边、外圈羽化 19.5 + 发散 7.6）。新图 pushLag 0.28s 晚半拍 y:1080→0 与旋转同终点（power2.out），推的是窗口内图像、蒙版原地。描边=同路径 stroke 作遮罩露新图像素，换图自动取色。到位定格末帧，无 fade-out。
【可改文案】底图（全屏压暗）（默认「./placeholder-1.pn」）、新图（花瓣窗口推入）（默认「./placeholder-2.pn」）、大标题（默认「林间晨光」）、英文小标（默认「SUMMER · 01」）、文案（逗号分隔逐行）（默认「光穿过叶隙落在车把上,整座森林都在轻」）、底部署名（默认「夏日 · 未至」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
