# 对比表视觉规范

## 方向

3 个对象 × 5 个维度的横向对比表，每行自动标出最优项，适合模型 / 工具 / 方案的多维比较。

## Palette

- Background: `#12100E`
- Foreground: `#F4EFE7`
- Accent: `#00FF00`
- Border: `rgba(244,239,231,0.14)`
- Muted: `rgba(244,239,231,0.55)`

## Typography

- 标题：`IBM Plex Mono` 700，64px
- 对象名：30px，700
- 维度名：22px，opacity 0.55
- 单元格值：26px，500

## Layout

- 标题 + 表格
- 首列维度，后 3 列对象
- 行高 88px，带横向分隔线

## Motion

- 标题入场
- 表头先出现
- 每行依次向上淡入
- 结束前整体上移淡出

## Avoid

- 不使用斑马纹、渐变、阴影
- 维度建议 4–6，过多拆表

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
