你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】文字遮罩开门
【分类】镜头动效
【用途】字重极大的标题当作取景框，框内透出缓缓横移的实拍画面；收束时字框放大退出，产品铺满全屏——字为门，产品为景。
【标签】遮罩 / 标题 / 开场
【画幅】1920×1080（16:9 横屏）
【时长】5 秒，动画确定性、首尾可循环

【视觉与设计规范】
超粗大标题字内部透出缓慢平移的产品画面，结尾字形放大 26 倍溢出、产品接管全屏，字是门产品在门里。
【可改文案】遮罩大字（默认「增长」）、产品层标题（默认「实时数据面板」）、强调色（默认「#00FF00」）、背景色（默认「#0A0A0F」）、文字色（默认「#F4F4F2」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
