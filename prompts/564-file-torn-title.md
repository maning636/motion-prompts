你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】撕纸标题卡（档案拼贴）
【分类】公文档案·文字与收尾
【用途】企业宣传场景的文字与收尾：撕纸标题卡（档案拼贴）。
【标签】file-torn-title
【画幅】1920×1080
【时长】5 秒，动画确定性、首尾可循环

【视觉与设计规范】
- ID: file-torn-title
- 风格：公文表单风：米色纸底 + 公文纸白 + 墨绿表头线与标题下划 + 公文红 accent（红章/红圈/红批注）；逐行盖章式入场（power4.in 砸章），红圈用 SVG 描边绘制，演完定格。
- 动效：档案 token。clip-path 撕纸边白条，撕开入场用 clip-path polygon 从 50% 窄条插值到全宽（power4.out）+ 旋转归位 -1.5°，高亮词黄底 clip 扫入。纯转场卡，无其他元素。

【可改文案】标题（默认「真正贵的是注意力」）、高亮词（默认「注意力」）、总时长（默认「5」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
