你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】霓虹浮动标签卡
【分类】字幕与重点标注
【用途】压实拍 overlay 浮动标签卡，深黑底荧光绿描边圆角卡四角 stagger 滑入，英文小标签+中文两行大字，可叠背景图，适合口播要点标注。
【标签】浮动标签 / overlay / 霓虹 / 要点标注
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
overlay 浮动标签卡（压实拍用），全屏基底上四角浮动要点卡。按 TEMPLATE-INGEST-STANDARD §2.5：时长 duration 变量化，动效演完定格最后一帧。
【可改文案】背景图（留空为深黑底+暗角）（默认「」）、卡1英文小标签（左上）（默认「WHAT YOU WRITE」）、卡1中文大字（默认「你在里面写下的内容」）、卡2英文小标签（左下）（默认「NO REPEAT」）、卡2中文大字（默认「不用每次再重复说」）、卡3英文小标签（右上）（默认「EVERY SINGLE TIME」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
