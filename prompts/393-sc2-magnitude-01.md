你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】数值错落充能
【分类】数据可视化
【用途】一组数值卡错峰升起，数值从零充能跳到真值，最大者荧光绿描边。
【标签】数值 / 错落 / 充能 / 差异化复刻
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
纸白 #F6F5EF + 36px 细网格底；顶部细线页眉（左 SC2 栏目 + 右 P.302/400 页码 mono），居中眉题；3-4 张 372×480 纸感数值卡（白底 + 3px 墨黑边 + 10px 硬投影）从底部 y+260 错峰升起（0.28s/张，expo.out），落位后数值从 0 以 power2.out 充能跳到真值（千分位格式化，1.4s），卡底荧光绿刻度线 scaleX 扫入；全部落定后最大者荧光绿描边 + 绿影替换黑影 + back.out 轻微放大 1.045 定格。底部荧光绿署名条（@老马AI研习社）推入。
【可改文案】眉题（默认「METRICS · 一组数字的赛跑」）、数值项（标签|数值，分号分隔）（默认「模板复用|1284;渲染提速|936」）、强调色（默认「#00FF00」）、总时长(秒)（默认「6」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
