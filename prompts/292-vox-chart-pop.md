# 拼贴数据卡

> 分类：杂志拼贴 ｜ 时长：6s ｜ 在线预览：https://maning789link.top/station.html

把下面整段提示词粘贴给任意 AI（Claude Code / Codex / 豆包 / DeepSeek……）即可生成同款动效。

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】拼贴数据卡
【分类】杂志拼贴
【用途】拼贴风柱状图带红色错位描边弹起，右上大数字压场，和 vox-cutout 同视觉系统的数据位。
【标签】数据 / 柱状图 / 拼贴 / Vox
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
按 TEMPLATE-INGEST-STANDARD §2.5 规范：时长 duration 变量化，动效演完定格；有 image 槽的素材必须放 assets/ 内。
【可改文案】顶部小标签（默认「数据 · DATA」）、标题（默认「这组数据，说明了一切」）、锁定背景（默认「./assets/bg.png」）、大数字（默认「73%」）、大数字说明（默认「的人都选错了重点」）、柱1标签（默认「刷题」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
