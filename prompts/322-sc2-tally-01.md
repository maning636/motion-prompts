你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】计数破阈礼花
【分类】数据可视化
【用途】大数字快速滚动破整百瞬间，顶部绿黑双色纸屑礼炮交叉喷发。
【标签】计数 / 礼花 / 里程碑 / 差异化复刻
【画幅】1920×1080（16:9 横屏）
【时长】5 秒，动画确定性、首尾可循环

【视觉与设计规范】
纸白 #F6F5EF + 36px 细网格底；顶部细线页眉（左 SC2 栏目 + 右 P.391/400 页码 mono），居中 mono 眉题。中央 330px 墨黑超大数字从 0 沿 power4.out 冲刺曲线滚动到 target（千分位格式），入场带 0.7→1 scale 充能。破阈前 0.35s 抢拍：48 片绿黑双色纸屑从顶部两侧交叉喷发（x 匀速 + y 上抛/坠落两段抛物线 + 自转，尾段淡出，固定种子伪随机）。到位瞬间数字 1.14→1 back.out 过冲回落 + 荧光绿冲击环扩散 + 绿色刻度块 scaleX + 说明行与 mono 副标淡入。末段数字 1.05 倍加深脉冲一次后定格，无收尾 fade-out。底部荧光绿署名条（@老马AI研习社）。
【可改文案】页眉左（卷/栏目）（默认「SC2 · 差异化复刻」）、页眉右（页码）（默认「P.391 / 400」）、眉题（默认「MILESTONE · 计数破阈」）、目标数字（默认「400」）、数字下方说明（默认「篇长文 · 全部发布完毕」）、强调色（默认「#00FF00」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
