# 简单流程图视觉规范

## 方向

4 步线性流程图，圆角矩形节点 + 箭头连接，适合讲解基础流程与操作步骤。

## Palette

- Background: `#12100E`
- Foreground: `#F4EFE7`
- Accent: `#00FF00`
- Node fill: `rgba(244,239,231,0.04)`
- Accent node fill: `rgba(0,255,0,0.10)`
- Link: `rgba(244,239,231,0.18)`

## Typography

- 标题：64px，700
- 节点名：22px，600
- 节点序号：18px，700

## Layout

- 标题区 + 横向排列的 4 个节点
- 节点间用箭头连接
- 首尾节点居中对齐

## Motion

- 标题入场
- 节点与箭头依次从左到右生长
- 结束前淡出

## Avoid

- 不使用 3D、阴影、渐变
- 步骤数固定为 4

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
