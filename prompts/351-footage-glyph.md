你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】视频填充文字开场（模式特效）
【分类】标题与开场
【用途】大字作 SVG 蒙版镂空透出视频：锚点字母先行，两侧字母 ease-out 归位，中央 aperture 裂开、字形复用为上下两实例退场，最后 scale 1.055 推近。MV/片头开场用。
【标签】文字蒙版 / 视频填充 / aperture / MV 开场
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
文字是蒙版上的透明区域（VIDEO × MASK，SVG mask：白底 + 黑色字形）。静态 video 标签带默认 src（0.6.x 视频槽三硬要求），场景无提前淡出。锚点字母定中，其余 ±1500px 两侧 power3.out 归位 1.15s；1.8s 起上下两半（clip-path 各半）反向退场；2.2s 起 scale→1.055 推近。定格纯视频画面。
【可改文案】大字文本（默认「THE OCEAN」）、视频路径（默认「./assets/placehold」）、锚点字母序号（0 起，空格不计）（默认「3」）、裂开幅度(px，上下各半)（默认「560」）、推近倍率（默认「1.055」）、总时长(秒)（默认「6」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
