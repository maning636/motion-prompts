# 倒计时弧线散点

> 分类：数据可视化 ｜ 时长：6s ｜ 在线预览：https://maning789link.top/station.html

把下面整段提示词粘贴给任意 AI（Claude Code / Codex / 豆包 / DeepSeek……）即可生成同款动效。

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】倒计时弧线散点
【分类】数据可视化
【用途】圆弧刻度逐格点亮倒数，到零瞬间弧散成粒子、答案数字砸入。
【标签】倒计时 / 弧线 / 数字 / 差异化复刻
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
纸白 #F6F5EF + 36px 细网格底；顶部细线页眉（左 SC2 栏目 + 右 P.390/400 页码 mono），居中 mono 眉题。舞台中央上半圆 21 根刻度条（-80°~+80° 切向排布，半径 300px，灰 #C9C8BE）逐格显影；倒数 from→1 每拍一秒：一组刻度点亮成荧光绿、超大 300px 墨黑数字 expo.out 砸入替换上一拍。到零瞬间整弧刻度沿径向散成粒子（固定种子伪随机，钉帧可复现），答案大数字（220px 墨黑）从 2.1 倍砸入 + 荧光绿冲击环扩散 + 高亮词绿块 scaleX 扫入 + mono 锁定行淡入。末段答案 1.04 倍脉冲一次后定格，无收尾 fade-out。底部荧光绿署名条（@老马AI研习社）。
【可改文案】页眉左（卷/栏目）（默认「SC2 · 差异化复刻」）、页眉右（页码）（默认「P.390 / 400」）、眉题（默认「COUNTDOWN · 倒数揭晓」）、倒数起点（默认「3」）、答案大数字（默认「400」）、高亮词（垫荧光绿）（默认「篇长文」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
