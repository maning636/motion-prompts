# 鼠标高亮视觉规范

## 方向

用于屏幕录制/教程演示中的鼠标移动与高亮提示。鼠标指针移动到目标位置后触发波纹扩散，引导观众视线。

## Palette

- Background: `#12100E`（透明通道便于后期叠加）
- Pulse: `#00FF00`
- Cursor: `#F4EFE7`

## 布局

- 鼠标指针为 SVG 箭头，尺寸 32×32px
- 波纹以目标点为中心向外扩散
- 起始/结束坐标可配置

## 动画

- 指针淡入
- 指针沿直线移动到目标位置
- 到达目标点后波纹从小到大扩散并淡出
- 指针轻微点击反馈

## Avoid

- 不使用阴影
- 不使用复杂轨迹

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
