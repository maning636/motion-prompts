你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】页面瀑布墙
【分类】镜头动效
【用途】三列页面卡在后仰的三维墙面上反向差速无尽滚动，辅以视差与镜头缓推，营造内容洪流般的体量感。
【标签】陈列 / 瀑布墙 / 体量
【画幅】1920×1080（16:9 横屏）
【时长】5 秒，动画确定性、首尾可循环

【视觉与设计规范】
3 列页面卡在 3D 后仰墙面上差速反向无限滚动，视差+镜头缓推做「内容多到流不完」的体量一览。
【可改文案】强调色（默认「#00FF00」）、背景色（默认「#0A0A0F」）、文字色（默认「#F4F4F2」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
