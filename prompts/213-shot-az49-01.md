# 级联生成树

> 分类：镜头动效 ｜ 时长：6s ｜ 在线预览：https://maning789link.top/station.html

把下面整段提示词粘贴给任意 AI（Claude Code / Codex / 豆包 / DeepSeek……）即可生成同款动效。

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】级联生成树
【分类】镜头动效
【用途】prompt 逐字敲出确认后，折角连线描线先行牵出节点、根→子→孙逐层错峰弹出一句话长成一棵树，收尾整棵呼吸一拍
【标签】生成 / 结构图 / 级联
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
prompt 逐字敲出确认后，折角连线描线先行牵出节点、根→子→孙逐层错峰弹出一句话长成一棵树，收尾整棵呼吸一拍。
【可改文案】生成指令（默认「帮我画出内容团队的组织架构」）、根节点（默认「内容团队」）、子节点1（默认「选题组」）、子节点2（默认「制作组」）、孙节点1（默认「文案」）、孙节点2（默认「剪辑」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
