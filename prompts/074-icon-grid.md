# 图标网格视觉规范

## 方向

6×8 的常用图标集合展示，适合作为设计系统或组件库的开场/收尾镜头。

## Palette

- Background: `#12100E`
- Foreground: `#F4EFE7`
- Accent: `#00FF00`
- Icon stroke: `#F4EFE7`
- Accent icon: `#00FF00`

## Typography

- 标题：64px，700
- 副标题：24px
- 图标下方无文字

## Layout

- 标题区 + 居中图标网格
- 6 列 × 8 行，间距 32px
- 图标尺寸 48px

## Motion

- 标题入场
- 图标依次淡入/缩放弹出
- 强调图标高亮闪烁
- 结束前淡出

## Avoid

- 不使用彩色填充图标
- 保持线性图标风格

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
