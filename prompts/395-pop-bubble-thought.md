你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】思考气泡
【分类】透明贴纸·叠加组件
【用途】需要「人物在犹豫 / 心里嘀咕一句」的时候，叠在任意画面上。
【标签】手绘弹跳 / 原子动效 / 可拼装 / 叠加组件 / 透明底
【画幅】480×270
【时长】3 秒，动画确定性、首尾可循环

【视觉与设计规范】
- ID: pop-bubble-thought
- 风格：透明底小画幅叠加组件（480×270，透明底可直接压在任意画面上）：clip-path 手绘形状 + 硬投影 + 高饱和贴纸配色；元素从画外甩入或 back.out 弹入，收尾定格。
- 动效：一句心里话先在气泡里鼓出来（back.out），随后四颗由大到小的圆点沿虚线往左下依次升起，定住之后各自以不同周期轻微浮动。坐标全部排死，文案再长也不会让尾迹跑位。

【可改文案】气泡里的一句话（默认「这段好像有点长」）、总时长（默认「3」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
