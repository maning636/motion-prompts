# 数据登记表（公文表单）

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】数据登记表（公文表单）
【分类】信息卡片
【用途】空表格逐格打字式填充的公文登记表：列名可配、行数据分号隔行逗号隔列。适合讲数据台账、统计口径、清单盘点。
【标签】公文 / 表格 / 逐行填充 / 打字
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
公文 token 同族。左对齐标题 + mono 录入信息行，斑马纹表格；单元格 span clip-path 从左到右快速揭开模拟打字录入（stagger 0.07 行优先），无章无圈，节奏密集。
【可改文案】表格标题（默认「自动化任务运行登记表」）、列名（逗号分隔）（默认「日期,任务,耗时,状态」）、行数据（分号隔行，逗号隔列）（默认「08-09,脚本定稿,12分钟,完成」）、总时长(秒)（默认「6」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
