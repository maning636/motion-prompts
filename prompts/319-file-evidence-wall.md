你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】证据墙（档案拼贴）
【分类】信息卡片
【用途】VOX 风档案拼贴：米色纸底 + 黄色马克笔高亮词，三张胶带贴的档案照片位（image 槽），红圈圈出重点照片，手写风批注。适合揭秘、考据、案例分析。
【标签】档案拼贴 / 证据墙 / 红圈标注 / 图槽
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

米色纸底 #EAE2CF + 暗角，黄色 #F5D73F 马克笔高亮词。档案照片白边 + 胶带贴角 + 墨绿 EXHIBIT 标签，红圈 #B03028 SVG 描边圈中间照片，红色斜体批注收尾。撕纸拼贴感，禁照搬 VOX 橙。

【技术要求】

2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
