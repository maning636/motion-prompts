你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】发牌飞入卡片墙
【分类】镜头动效
【用途】整摞卡片仿若牌局开甩，硬加速抛进网格并沿 z 轴拱起，回稳后仍有残影——内容量大时的模板库秀场。
【标签】卡片墙 / 发牌 / 网格 / 飞入
【画幅】1920×1080（16:9 横屏）
【时长】5 秒，动画确定性、首尾可循环

【视觉与设计规范】
一摞卡像发牌一样硬加速甩进网格，带 z 弧顶、过冲 settle 与残影，适合展示内容量大/模板库。
【可改文案】段落标题（默认「内容库」）、卡片数量（默认「15」）、收尾文案（默认「全部模板已就位」）、强调色（默认「#00FF00」）、背景色（默认「#0A0A0F」）、文字色（默认「#F4F4F2」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
