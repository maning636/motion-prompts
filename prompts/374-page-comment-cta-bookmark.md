你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】评论关键词 CTA 横幅（书签抽出式）
【分类】字幕与重点标注
【用途】底部黑横幅固定，关键词荧光绿书签从横幅上缘 back.out 抽出，回合一换；横幅内 CTA 文案跟随切换。
【标签】书页 / CTA / 书签 / 评论关键词
【画幅】1920×1080（16:9 横屏）
【时长】5 秒，动画确定性、首尾可循环

【视觉与设计规范】
纸白 #F6F5EF + 36px 细网格底；顶部细线页眉（左 VOL/栏目 + 右页码 mono）scaleX 扫入，中部 mono 引导行（箭头上下浮动）；底部墨黑横幅（高 150px，白字 42px CTA + 左侧 mono 栏标）从屏下 expo.out 推入，荧光绿书签条（300×196，墨黑描边）从横幅上缘 overflow 容器内 back.out(1.6) 抽出，书签上评论关键词每 0.9s 一换：先 power2.in 缩回横幅、换字、再 back.out 抽出，连换 3 个；底部荧光绿署名条（@老马AI研习社）推入定格。
【可改文案】页眉左（卷/栏目）（默认「VOL.15 · 视觉动效库」）、页眉右（页码）（默认「P.379 / 400」）、横幅 CTA 文案（默认「在评论区扣出关键词，领取完整清单」）、评论关键词（逗号分隔 3 个）（默认「清单，模板，教程」）、强调色（默认「#00FF00」）、总时长(秒)（默认「5」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
