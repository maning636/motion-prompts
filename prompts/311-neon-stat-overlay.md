# 荧光绿数字大字压屏

> 分类：透明叠加 ｜ 时长：6s ｜ 在线预览：https://motion.maning789link.top

把下面整段提示词粘贴给任意 AI（Claude Code / Codex / 豆包 / DeepSeek……）即可生成同款动效。

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】荧光绿数字大字压屏
【分类】透明叠加
【用途】中央超大白色发光数字从0递增至目标值，下方白字标签加绿色进度横条展开，支持背景图压暗叠加，口播报数据 overlay 用。
【标签】数字 / 百分比 / 数据强调 / 口播
【画幅】1920×1080（16:9 横屏）
【时长】6 秒，动画确定性、首尾可循环

【视觉与设计规范】
按 TEMPLATE-INGEST-STANDARD §2.5 规范：imgBg image 槽 + duration 变量化，动效演完定格最后一帧。
【可改文案】背景图（空则深黑底+暗角）（默认「」）、目标数字（从0递增到此值）（默认「90」）、数字后缀（默认「%」）、数字下方标签（默认「的 AI 用户」）、总时长（秒，演完定格）（默认「6」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
