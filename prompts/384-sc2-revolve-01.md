# 纸卡 3D 轮播

> 分类：杂志拼贴 ｜ 时长：7s ｜ 在线预览：https://motion.maning789link.top

把下面整段提示词粘贴给任意 AI（Claude Code / Codex / 豆包 / DeepSeek……）即可生成同款动效。

---
你是一位顶级前端动效工程师。请用 HTML + CSS + GSAP（CDN 引入）实现下面这个视频动效，输出一个自包含的单文件 HTML。

【动效名称】纸卡 3D 轮播
【分类】杂志拼贴
【用途】竖版书页卡在 3D 环形轨道上轮换，当前卡转正放大、两侧卡倾斜压暗。
【标签】3D / 轮播 / 书页卡 / 差异化复刻
【画幅】1920×1080（16:9 横屏）
【时长】7 秒，动画确定性、首尾可循环

【视觉与设计规范】
纸白 #F6F5EF + 36px 细网格底；顶部细线页眉（左 SC2 栏目 + 右 P.389/400 页码 mono）scaleX 扫入，居中 56px 眉题大标题，下方 mono 参数行。中央 3D 舞台（perspective 1500）：3 张 320×460 竖版纸卡按 `rotateY(i*120°) translateZ(430)` 排成环形；卡正面白底 + 3px 墨黑边 + 10px 硬偏移投影（右上角 mono 卡号 + 荧光绿色块 + 标题/说明，文字单层避免背面文字层被判遮挡），卡背为纯图形（墨黑底 + 荧光绿网格 + 圆环，无文字），双面 backface-visibility:hidden。动效：整环 rotateX 俯角落位 → 一口氣快转 480°（0.55-1.6s）→ 两步 120° 步进（3.15 / 5.15 起手），每卡朝前静止停驻 ≥1s（1.6-3.15 / 3.85-5.15 / 5.9-7.02 三个窗口），总计 720° 两圈；5.9s 后完全静止定格，无 fade-out（末尾隐形 tween 拉满时间轴防尾帧空白）。底部荧光绿署名条（@老马AI研习社）推入。
【可改文案】页眉左（卷/栏目）（默认「SC2 · 差异化复刻」）、页眉右（页码）（默认「P.389 / 400」）、眉题（默认「CAROUSEL 3D · 纸卡轮播」）、卡片（标题|说明，分号分隔，3 张）（默认「灵感采集|碎片想法先进篮子;结构拆解」）、强调色（默认「#00FF00」）、总时长(秒)（默认「7」）

【技术要求】
1. 先画出动画最完整时刻的静态布局，再编写 GSAP 时间线；动画必须是确定性的（同一时刻刷新，画面一致）。
2. 文案、数字、颜色集中定义为 JS 常量放在文件顶部，方便二次修改。
3. 只输出 HTML 代码，不要解释，不要省略。
